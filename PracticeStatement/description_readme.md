# C Programming Question Bank — Overview

A curated, collection of scenario-based C programming questions designed for UG students and faculty FDPs. Each question is provided as a separate .md file, with a consistent format that emphasizes logic development, clean API design, and edge-case thinking—ideal for lab manuals, assignments, quizzes, and interviews.

## What’s Inside
Each question file follows a consistent, README-friendly structure:
* Title
* Level (Easy / Difficult)
* Concepts (targeted topics)
* Scenario (realistic, embedded-friendly context)
* Problem Statement
* Requirements (constraints, validations, complexity)
* Function Details (name, arguments, return value, behavior)
* Solution Approach (high-level hints or expected thinking)
* Tasks to Perform (step-by-step guide)
* Test Cases (≥ 5, covering edge cases)

## Coverage Map (Quick Index)
* Fundamentals: Variables & Data Types; Enums
* Expressions: Operators, Precedence, Short-Circuiting
* Control Flow: if/else, switch, State Machines, Hysteresis
* Loops: for, while, do-while, ring buffers, parsers
* Arrays & Strings: 1D scans, stable segment detection, 2D grid search
* Functions & Parameters: by-value, const pointers, API contracts
* Pointers: pointer ranges, tokenization, strided math, in-place rotation
* Callbacks: function pointers and event handling
* Structs/Unions/Bit-fields: register packing, tagged unions
* Dynamic Memory: growth patterns, realloc safety, compaction policies
* File I/O: text and binary streaming, validation, indexing
* Qualifiers & API Design: const, volatile, static, extern, typedef
* Preprocessor & Macros: safe bit macros, field ops, do{ }while(0)
* Algorithms: binary search, stable mergesort with scratch
